# PCcUpdater

Telegram-бот для обновления удаленного управления с помощью:

- последнего релиза GitHub;
- загрузки `.zip` файла в чат.

## Быстрый старт

1. Установите зависимости:

```bash
pip install -r requirements.txt
```

2. Задайте переменные окружения:

```powershell
$env:TELEGRAM_BOT_TOKEN="<bot_token>"
$env:PC_UPDATER_TARGET_DIR="C:\Users\Gleb\pc"
$env:PC_UPDATER_GITHUB_REPO="owner/repo"
```

3. (Опционально) Укажите exe для перезапуска и автозапуска, если в папке несколько `.exe`:

```powershell
$env:PC_UPDATER_TARGET_EXE="RemoteControl.exe"
$env:PC_UPDATER_AUTOSTART_NAME="RemoteControl"
```

4. Запустите бота:

```bash
python src/main.py
```

## Команды бота

- `/update_github` — скачивает последний релиз GitHub и обновляет файлы.
- `/update_zip` — ожидает `.zip` файл в чат и обновляет файлы.

## Как происходит обновление

1. `.zip` скачивается в системную временную директорию.
2. Архив распаковывается во временную папку.
3. Содержимое папки управления синхронизируется с архивом:
   - файлы, которых нет в архиве, удаляются;
   - новые файлы добавляются;
   - существующие перезаписываются.
4. После обновления exe перезапускается и заново добавляется в автозапуск.

## Дополнительно

- Для GitHub можно использовать токен доступа:

```powershell
$env:PC_UPDATER_GITHUB_TOKEN="ghp_..."
```

- Бот принимает `.zip` только в личных сообщениях.
